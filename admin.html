☁️ Hướng dẫn kết nối Supabase (Lưu trữ Online miễn phí)

Hiện tại web có thể chạy thử ngay trên trình duyệt của bạn. Khi muốn xuất bản web lên mạng để mọi thành viên cùng truy cập và upload ảnh trực tuyến miễn phí (không cần thẻ ngân hàng), bạn chỉ cần làm 3 bước trong 2 phút với Supabase:

  1. Đăng ký tài khoản miễn phí tại supabase.com → tạo Project mới, vào mục Authentication → Users → Add User để tạo tài khoản email/mật khẩu cho Admin CLB.
  2. Vào mục SQL Editor trên Supabase, bấm New Query, dán đoạn mã dưới đây và nhấn Run để tự động tạo bảng thành viên + kho ảnh member-photos:
-- 1. Tạo bảng lưu trữ thành viên & confession các Gen
create table if not exists public.members (
    id text primary key,
    name text not null,
    gen integer not null default 1,
    term text default '',
    tier integer not null default 4,
    sort_order integer not null default 10,
    role text default '',
    department text default '',
    cohort text default '',
    avatar_url text default '',
    quote text default '',
    confession_title text default '',
    confession text default '',
    created_at timestamptz default now()
);

-- 2. Bật phân quyền: Ai cũng xem được Phòng truyền thống, chỉ Admin đăng nhập mới được Thêm/Sửa/Xóa
alter table public.members enable row level security;

create policy "Cho phep moi nguoi xem thanh vien"
on public.members for select using (true);

create policy "Chi Admin dang nhap duoc quan ly"
on public.members for all to authenticated using (true) with check (true);

-- 3. Tạo kho lưu trữ ảnh member-photos công khai
insert into storage.buckets (id, name, public)
values ('member-photos', 'member-photos', true)
on conflict (id) do nothing;

create policy "Xem anh cong khai"
on storage.objects for select using (bucket_id = 'member-photos');

create policy "Admin upload anh"
on storage.objects for insert to authenticated with check (bucket_id = 'member-photos');

3. Vào Project Settings → Data API trên Supabase, copy Project URL và anon public key dán vào file js/supabase-config.js là hoàn tất!
